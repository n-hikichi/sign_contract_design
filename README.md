# sign_contract_design

## 概要

このリポジトリは、2025年夏の旧電子契約システムのコードリポジトリをベースとした、UIデザイン更新のプロトタイプです。

## 目的

- **UIの試験的更新**: 最新のデザインシステムを適用したプロトタイプ実装
- **マイグレーション参考**: 最新のコードリポジトリへの移行を検討する際の参考リポジトリとして活用

## ドキュメント

| ドキュメント | 内容 |
|-------------|------|
| [FILES.md](./FILES.md) | ファイル構成の説明 |
| [UI_MODERNIZATION_KNOWHOW.md](./UI_MODERNIZATION_KNOWHOW.md) | UI最新化のノウハウ・ガイド |

## ビルド・実行方法

```bash
cd edoc_cli
npm install    # 依存関係のインストール
npm start      # 開発サーバー起動（http://localhost:3000）
```

## 備考

本リポジトリは実験的なプロトタイプであり、プロダクション環境での使用は想定していません。
